# Query 023: SUM

## Objective
Tests the `SUM` aggregate function. Validates that `SELECT SUM(field)` maps to a `$group` stage with `_id: null` (unpartitioned aggregate) and a `$sum` accumulator over the target field.

## SQL Query
```sql
SELECT SUM(total) AS revenue FROM orders;
```

## Expected MongoDB Pipeline
```javascript
[
  {
    $group: {
      _id: null,
      revenue: { $sum: "$total" }
    }
  },
  {
    $project: {
      _id: 0,
      revenue: 1
    }
  }
]
```

## Expected Behavior
Returns a single document like `{ revenue: 148250.75 }` containing the sum of the `total` field across all 300 orders. The `_id: null` in the `$group` stage means all documents are collapsed into one aggregate result.

## SQL Constructs Tested
- `SUM(field)` → `$sum: "$field"` accumulator
- Global (unpartitioned) aggregate with `_id: null`
- Column alias on aggregate result (`AS revenue`)
- `$project` to strip `_id` from the output
