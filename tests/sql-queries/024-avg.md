# Query 024: AVG

## Objective
Tests the `AVG` aggregate function. Validates that `SELECT AVG(field)` maps to a `$group` with `_id: null` and an `$avg` accumulator, returning the arithmetic mean of all non-null values.

## SQL Query
```sql
SELECT AVG(rating) AS avg_rating FROM products;
```

## Expected MongoDB Pipeline
```javascript
[
  {
    $group: {
      _id: null,
      avg_rating: { $avg: "$rating" }
    }
  },
  {
    $project: {
      _id: 0,
      avg_rating: 1
    }
  }
]
```

## Expected Behavior
Returns a single document like `{ avg_rating: 3.87 }` — the average `rating` across all 50 products. MongoDB's `$avg` automatically ignores `null` and missing values, consistent with SQL `AVG` behavior. The result is a floating-point number.

## SQL Constructs Tested
- `AVG(field)` → `$avg: "$field"` accumulator
- Global unpartitioned aggregate (`_id: null`)
- Floating-point aggregate result
- Column alias (`AS avg_rating`)
